# aws-secrets-manager

Creates one or more AWS Secrets Manager secrets from a typed map, following the
ECV module standard. Each secret can store a supplied value, store a value
generated by the Secrets Manager `GetRandomPassword` API, or be created empty for
an external owner to populate.

## Usage

```hcl
module "secrets" {
  source = "git::https://gitlab.ecvmsp.com/ecv-ph-tech-team/ph-modernization-team/terraform-aws-module.git//modules/security/aws-secrets-manager?ref=v0.2.0"

  providers = { aws = aws.workload }

  project_name = "my-project"
  environment  = "dev"

  secrets = {
    api_key = {
      name          = "api-key"
      description   = "Third-party API key"
      secret_string = var.api_key
    }

    db_password = {
      name            = "db-password"
      description     = "Generated application DB password"
      generate_random = true
    }

    external = {
      name        = "external-managed"
      description = "Populated out-of-band; created empty here"
    }
  }

  tags = { CostCenter = "payments" }
}
```

## Providers

This module uses the **default** `aws` provider. Point it at your workload
account by redirecting it in the module block:

```hcl
providers = { aws = aws.workload }
```

The AWS provider version is **not** pinned in the module; the root pins it. The
standard account tags come from the root's provider `default_tags`; the module
only adds a `Name` tag and whatever you pass in `tags`.

## Inputs

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `project_name` | string | — | First part of every resource name. |
| `environment` | string | — | dev / uat / prod. |
| `secrets` | map(object) | `{}` | Secrets to create (see `variables.tf`). |
| `tags` | map(string) | `{}` | Extra tags merged onto every resource. |

Each `secrets` entry supports `name`, `description`, `secret_string`,
`generate_random`, `random_password_length`, `exclude_punctuation`, and
`recovery_window_in_days`. A version is written only when `secret_string` is set
or `generate_random = true`.

## Outputs

| Name | Description |
|------|-------------|
| `secret_arns` | Map of key to secret ARN (sensitive). |
| `secret_ids` | Map of key to secret ID. |
| `secret_names` | Map of key to secret name. |
| `version_ids` | Map of key to created version ID. |
